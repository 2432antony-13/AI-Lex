## 评测 localhost:3002 项目与 AI Lex 框架化方案

### 关键发现
- localhost:3002 上的「小浣熊比赛合规产品」并非独立项目，而是 AI Lex 的比赛 Demo 壳
- 纯前端 Next.js 14 项目，9 个页面，3 个硬编码 Demo 场景
- 无 API/DB/LLM/Auth，所有数据在 lib/demo-data.ts

### 两项目对比
- 小浣熊：Demo 壳，展示 UI + 概念，无核心算法
- AI Lex：完整引擎，含四层合规管道 + Agent 管道 + 知识图谱 + Prisma DB

### 框架化策略（三层隔离）
1. 公开层：小浣熊 Demo 壳 → 比赛直接部署，不泄露核心代码
2. 隔离层：对外版概念文档 → 路演叙事
3. 私有层：AI Lex 引擎 → 赛后通过 API 注入 Demo 壳
