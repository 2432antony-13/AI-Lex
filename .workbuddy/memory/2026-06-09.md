# 2026-06-09 DeepSeek V4 Pro API 调优

## 改动概览
对项目中所有 DeepSeek API 接入点进行全面扫描和调优。

## 改动文件
1. **src/lib/llm.ts** — 核心封装层
   - temperature: 0.1 → 0（合规分析更精确）
   - 超时动态化：flash=30s, pro=90s, pro+thinking=120s（原固定60s）
   - 新增 retry 机制：默认最多2次重试，含指数退避(1s/2s/4s)
   - 5xx/429 可重试，4xx 不重试，超时/网络错误可重试

2. **src/app/api/compliance/llm-analyze/route.ts** — API 路由
   - POST：新增 FEATURE_LLM feature flag 检查，false 返回503
   - GET：同样添加 FEATURE_LLM 检查
   - Zod schema：mode 默认值 full→quick（更安全）

3. **src/app/demo/page.tsx** — Demo 页面
   - 新增 llmMode 状态（quick/full）
   - 新增 Quick/Full 子模式切换开关（仅 AI 分析模式下显示）
   - handleLLMAnalyze 不再硬编码 "quick"，改为传递 llmMode
   - spinner 文案根据实际模型动态显示
   - 按钮文案区分 Quick/Full

4. **.env.example** — 模板配置
   - 新增 DEEPSEEK_API_KEY + DEEPSEEK_BASE_URL 占位
   - 完善 Feature Flags 注释说明

5. **.env.local** — 本地配置
   - 新增 FEATURE_LLM=true
