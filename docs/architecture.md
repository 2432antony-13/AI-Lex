# 系统架构

AI-Lex 采用“确定性规则优先、生成式模型辅助、人工最终复核”的分层结构。

## 处理链路

1. **事实层**：以结构化字段记录产品功能、数据处理、模型来源、用户范围和部署地区。
2. **规则层**：根据事实标签检索候选义务、适用条件与审查材料。
3. **分析层**：生成风险项，并保留事实输入、规则依据和判断状态之间的关联。
4. **生成层**：在启用大模型时辅助解释和起草；模型不负责确定法律事实或作出最终结论。
5. **复核层**：由专业人员确认事实完整性、规则时效性、法域适用和输出结论。

## 代码结构

- `src/app`：页面与服务端接口
- `src/components`：交互组件
- `src/lib`：规则库、合规分析、模型与数据访问
- `prisma`：可选持久化模型

## 运行模式

默认演示模式关闭认证、持久化和模型调用。通过 `.env.local` 中的功能开关可逐项启用外部能力，密钥不进入仓库。

## 当前限制

内置规则及示例数据用于产品研究，不构成完备、持续更新的法律数据库。生产使用还需要建立规则版本管理、来源校验、权限控制、审计日志与专业复核机制。
