# AI-Lex

**From product facts to evidence-backed compliance review.**

An auditable workflow prototype for AI product teams: capture facts, match rules, assess risk, draft documents and seek human review.

[Issues](https://github.com/2432antony-13/AI-Lex/issues) · [Docs](../../docs/README.md)

## Current status

Research and demonstration stage. External models, authentication and persistence are disabled by default. A successful build is not legal or rule-accuracy acceptance.

## Quick start

Node.js 20; see .env.example for configuration. Database migrations are not routine validation commands.

```bash
npm ci
# Copy .env.example to .env.local
npm run dev
# http://localhost:3000
npm run build
```

## Capabilities and scope

Structured product facts; rules and risk evidence; compliance calendar; review history and document drafts.

A missing deployment region must remain unknown. Legal sources, applicability and generated content require independent review.
